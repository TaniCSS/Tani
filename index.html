Introduction #

⚡ Zero-JS
🎨 OKLCH Colors
🌗 Dark Mode
🌐 RTL

The CSS framework that needs no JavaScript.

Tani is a lightweight, utility-first CSS framework with God-Mode features: scroll-driven animations, container queries, glassmorphism, gold accents and a complete zero-JS component library. Drop in one file and build premium interfaces.

Get Started Browse Components

🪄

Zero JS Components

Perceptually uniform palette with auto-generated hover states.

📦

Container Queries

Installation #

CDN

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/TaniCSS/Tani@v2.2.0/dist/css/tani.min.css">

Download

<link rel="stylesheet" href="./dist/css/tani.css">

NPM

npm install tanicss
💡

Tani is a single static CSS file. There is nothing to compile — just link it and start using classes.

Quick Start #

<!DOCTYPE html>
<html lang="en" data-theme="dark">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <link rel="stylesheet" href="./dist/css/tani.css">
</head>
<body>
  <div class="container">
    <h1 class="text-center">Hello, Tani!</h1>
    <button class="btn btn-primary">Click Me</button>
  </div>
</body>
</html>

That is the entire setup. Every class in this documentation is available immediately.

Design Tokens #

Design Tokens

Tani is driven by CSS custom properties — change a handful of variables to re-skin your entire app.

:root {
  --primary: oklch(70% 0.18 70);
  --radius-md: 8px;
  --shadow-md: 0 4px 6px -1px oklch(0% 0 0 / 0.1);
  --text-base: clamp(1rem, 0.95rem + 0.25vw, 1.125rem);
}

RTL & Dark Mode #

Tani is built on logical properties, so RTL works automatically. Dark mode is native and needs no toggle (system preference) — or force it with the .dark-mode class.

<html lang="ar" dir="rtl">
  <div class="ms-4">This margin is on the inline-start side.</div>
</html>
/* force themes */
<html class="dark-mode"> /* dark */
<html class="light-mode"> /* light */

Customization #

Override tokens or extend with your own classes. Because Tani is plain CSS, you can layer your theme after the framework import.

:root {
  --primary: oklch(65% 0.2 145); /* your brand */
  --radius-md: 12px;
  --gold: oklch(80% 0.12 60);
}
.brand-btn { background: var(--gold); color: #1a1205; }
🎨

Prefer a build step? Tani tokens are plain CSS variables — consume them from JS or a preprocessor with no extra tooling.

FAQ #

Is Tani really zero-JavaScript?

Yes for all components. A few conveniences (toast demo, modal close) use tiny native APIs, but nothing is required to render the UI.

Does it work without a build step?

Absolutely. Link the stylesheet and you are done.

How big is it?

~55KB raw, ~15KB gzipped for the full framework.

Browser support?

All modern browsers. Cutting-edge features (scroll animations, anchor positioning, container queries) degrade gracefully.
