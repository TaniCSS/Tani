🌙 Dark Mode

Tani v2.0 includes native dark mode that automatically adapts to the user's system preferences. No JavaScript toggle required!

How It Works

Dark mode uses the prefers-color-scheme media query to detect the user's system theme:

/* Dark mode is automatically applied when system is in dark mode */
@media (prefers-color-scheme: dark) {
  :root {
    --body-bg: oklch(15% 0.01 250);
    --body-color: oklch(95% 0.01 250);
    /* ... more variables ... */
  }
}
Tip: Try switching your system to dark mode - this entire documentation will automatically adapt!

Manual Toggle (Optional)

If you want to add a manual toggle button, you can use this JavaScript:

// Optional: Manual dark mode toggle
function toggleDarkMode() {
  document.documentElement.classList.toggle('dark-mode');
}

// CSS for manual toggle
.dark-mode {
  --body-bg: oklch(15% 0.01 250);
  --body-color: oklch(95% 0.01 250);
}

📦 Container Queries

Components that adapt based on their container size, not the viewport. This is the future of responsive design!

Responsive Card

Small Container

This card is in a narrow container.

Large Container

This card is in a wide container and can use horizontal layout.

/* Card automatically becomes horizontal when container is > 400px */
.card {
  container-type: inline-size;
  container-name: tani-card;
}

@container tani-card (min-width: 400px) {
  .card-horizontal-layout {
    display: grid;
    grid-template-columns: 1fr 2fr;
  }
}
Tip: Container queries are perfect for reusable components that need to adapt to different layouts (sidebar vs main content).

🐛 Debug Mode

Visual layout inspector that helps you debug spacing, alignment, and component boundaries.

Enable Debug Mode

Simply add the tani-debug class to your <body> tag:

<body class="tani-debug">
  <!-- Your content -->
</body>
Tip: Debug mode adds colored outlines to all elements, making it easy to see spacing issues, misaligned components, and layout problems.

🌐 RTL/LTR Support

Tani v2.0 has native RTL support using CSS Logical Properties. No extra classes or configuration needed!

How It Works

All spacing utilities use logical properties that automatically flip based on text direction:

/* These automatically flip in RTL mode */
.container {
  margin-inline: auto; /* margin-left/right in LTR, flips in RTL */
  padding-inline: 1rem; /* padding-left/right in LTR, flips in RTL */
}

.text-start {
  text-align: start; /* left in LTR, right in RTL */
}

.mr-3 {
  margin-inline-end: 1rem; /* margin-right in LTR, margin-left in RTL */
}

Enable RTL

Just set the dir attribute on your HTML:

<!-- For RTL languages (Arabic, Hebrew, Persian, etc.) -->
<html lang="ar" dir="rtl">
  <!-- Your content -->
</html>

<!-- For LTR languages (English, etc.) -->
<html lang="en" dir="ltr">
  <!-- Your content -->
</html>
Note: RTL support is built into the core. You don't need a separate RTL stylesheet or configuration.

📋 Migration Guide (v1 → v2)

Upgrading from Tani v1.15.0 to v2.0 is fully backward compatible. All your existing code will continue to work!

What's Changed

  • Colors: Migrated from HEX to OKLCH (better color accuracy)
  • Spacing: Now uses fluid values with clamp()
  • Typography: Fluid scaling from mobile to 4K
  • Dark Mode: Native support (no JS needed)
  • RTL: Built-in support using logical properties

What's New

  • Scroll-driven animations (.tani-fade-in, .tani-scale-in)
  • Container queries for cards
  • Zero-JS components (native <dialog> and <details>)
  • Debug mode (.tani-debug)
  • GPU-accelerated utilities (.tani-gpu, .tani-content-visibility)

Breaking Changes

None! Tani v2.0 is 100% backward compatible with v1.15.0. All existing classes and components continue to work exactly as before.

Tip: You can upgrade to v2.0 without changing any existing code. New features are opt-in and can be adopted gradually.
