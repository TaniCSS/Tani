About Tani

Tani began as a bet: could a CSS framework feel premium and still need zero JavaScript? The answer is yes. Every component — modals, tabs, dropdowns, carousels, popovers — is pure CSS, leaning on modern features like :has(), anchor positioning, container queries and scroll-driven animations.

Principles

  • Zero-JS — the UI works without a single script tag.
  • Zero-build — link one file and you are done.
  • Additive — new versions only add classes, never break.
  • Premium by default — OKLCH color, glass, gold, motion.
